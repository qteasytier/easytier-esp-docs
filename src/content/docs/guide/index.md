title: 项目概览
---

**EasyTier-ESP** 是一个使用 C++20 编写的 ESP-IDF 组件，它实现了一个 EasyTier 异地组网工具的轻量级协议，便于把 ESP32 接入既有 EasyTier 虚拟网络。无须公网 IP 与复杂配置，轻松实验物联网设备的异地安全互联。

- 组件注册表：`myqfeng/easytier-esp`
- 当前适配：ESP-IDF >=6.1
- 已验证目标：ESP32-S3-N16R8
- 许可证：LGPL-3.0

## 它解决什么问题

ESP32 通常没有公网地址，也不适合运行完整的上游 EasyTier 进程。EasyTier-ESP 把“ 接入 EasyTier 虚拟网络”所需的基本能力使用 C++ 和 ESP-IDF SDK 进行重新实现，以适配性能有限的 ESP32 单片机，让使用 ESP32 的物联网设备也拥有异地组网的能力。

## 项目特点

- 兼容 EasyTier：让 ESP32 无缝接入已有 EasyTier 虚拟网络。
- 安全加密支持：支持 AES-GCM-128 加密协议，保障数据安全。
- OSPF智能路由：自动选择最佳链路，降低延迟，提高吞吐量。
- 高可用性：支持多服务器连接，自动切换健康链路，提升稳定性。
- 资源自定义：可通过 KConfig 自定义资源参数，适配不同性能与需求。

## 与上游 EasyTier 的关系

EasyTier-ESP 不是独立的组网协议，而是 EasyTier 组网协议在 ESP32 上的实现：

- 配置字段语义尽量对齐上游；
- 握手、保活、路由同步与上游兼容；
- 只实现与 ESP32 客户端性能相匹配的子集；

目标场景是“把 ESP32 接入一个已经在运行的 EasyTier 网络”，而不是让 ESP32 承担网络入口或中继服务器的角色。
